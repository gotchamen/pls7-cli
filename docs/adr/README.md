# Architecture Decision Records

This directory stores future Architecture Decision Records (ADRs).

Use ADRs for durable design decisions that affect architecture, dependency direction, storage, protocols, or public interfaces.

Recommended filename format:

```text
NNNN-short-decision-title.md
```

Recommended structure:

```markdown
# NNNN: Decision Title

## Status

Proposed | Accepted | Superseded

## Context

## Decision

## Consequences
```
