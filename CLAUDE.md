# Claude Code Instructions

This repository uses [AGENTS.md](./AGENTS.md) as the canonical tool-neutral source for coding agent and contributor rules.

Claude Code users should read `AGENTS.md` first. Project-specific Claude skills remain available under `.claude/skills/`:

- `/pls7-gh-pr` for pull request title and description generation.
